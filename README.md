# Resend Clone

This repository contains a frontend clone of the Resend website, created purely for learning and practice purposes.

## About

The goal of this project was to improve my frontend development skills by recreating the design and interactions of the Resend landing page using only core web technologies.

This is **not an official Resend product** and is **not intended for commercial use**. It is a personal tutorial/trial project built to understand modern UI design, layouts, animations, and responsive web development.

## Purpose

This project was created to:

- Practice HTML, CSS, and JavaScript.
- Learn how modern SaaS landing pages are structured.
- Improve responsive design skills.
- Understand animations, transitions, and interactive UI elements.
- Build confidence by recreating real-world websites.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
